# Dance Academy Registration and Feedback Website

## About the Project
The Dance Academy Registration and Feedback Website is a web-based application developed to provide an online platform for a dance academy. It showcases academy information, courses, achievements, and activities while allowing students to register online and share feedback.

## Features
- Online student registration
- Display of dance courses and activities
- Academy achievements and information
- Student feedback submission
- Contact information and enquiry facility
- User-friendly and responsive interface

## Technologies Used

**Frontend:**
- HTML
- CSS
- Bootstrap
- JavaScript

**Backend:**
- Java
- Java Servlets
- JSP
- JDBC

**Database:**
- MySQL

**Development Tools:**
- Eclipse IDE
- MySQL Workbench
- Apache Tomcat

## Project Structure
- `src` – Java source code and application files
- `dao` – Database operations
- `model` – Data model classes
- `servlet` – Request handling
- `util` – Database connection utilities

## Purpose
The main objective of this project is to make dance academy information easily accessible and simplify student registration and feedback through an online platform.

## Future Enhancements
- Online payment integration
- Email notifications for registration
- Student login and profile management
- Admin dashboard for managing courses and registrations
